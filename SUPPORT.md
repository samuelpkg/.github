# Support

Thanks for using Samuel. Here is where to go depending on what you need.

## Ask a question or discuss an idea

Use [Discussions](https://github.com/samuelpkg/samuel/discussions) on the main `samuel` repo. Good for usage questions, design discussion, and sharing what you built.

## Report a bug

Open an issue on the repo where the bug lives:

- Framework or CLI bug → [samuel issues](https://github.com/samuelpkg/samuel/issues/new/choose)
- A specific plugin → that plugin's own repo (`github.com/samuelpkg/samuel-<name>`)

Include your `samuel version`, the exact commands you ran, and expected vs. observed behavior.

## Read the docs

The reference documentation lives at <https://samuelpkg.github.io/samuel/> (installation, CLI reference, RFDs).

## Report a security issue

Do **not** open a public issue. Use a [private security advisory](https://github.com/samuelpkg/samuel/security/advisories/new). See [SECURITY.md](SECURITY.md).
